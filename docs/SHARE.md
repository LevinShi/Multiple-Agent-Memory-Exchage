# 社区分享文案 · v0.2.1-preview

我把自用的本地多 Agent 共享记忆整理成了 Local Agent Memory，准备开放预览试用。

它解决的是换 AI 编程工具后接不上项目进度的问题：按项目授权读上下文、完成工作后保存少量增量，再由另一工具接续。Python 标准库 + Markdown，无云端中转，支持来源、修订和本地状态页；提供 Codex、Cursor、ZCode、MiniMax Code 的入口模板。

本版还有独立的私有聊天导入器和实验性 Gemini Chrome 选定会话采集。原文默认私有，共享摘要要单独选择项目；不是全历史备份。Gemini 只做过 macOS 短会话实测，目前在线测试暂停，建议先运行两套完全离线的演示。

本机 32 项 Python 测试通过，Codex 与 MiniMax Code 在维护者环境有自然语言接力记录；其他客户端、全新环境还需要大家反馈。没有 ChatGPT 自动采集、语义检索或 Gemini 原生客户端直接采集。权限是合作型 Agent 的工作流约束，不是安全沙箱。

请从 README 开始，用非敏感合成项目尝试两个工具接力。反馈系统/客户端版本、规则加载与脱敏的实际命令；不要上传个人记忆库。发布时再附真实仓库地址。详见 docs/RELEASE.md 的交付范围和剩余验收。
