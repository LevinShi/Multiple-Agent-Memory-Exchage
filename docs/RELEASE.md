# v0.2.1-preview 交付与发布清单

2026-11-05。结论：可以作为面向 AI 爱好者的实验性预览分享；离线发行准备完成后，公开仓库已创建，远端验证与Release状态见GitHub。本项目没有整体完结。

## 本版交付

|交付|已完成边界|
|---|---|
|本地共享记忆核心|默认拒绝；按项目 read/write/export；独占/多端共享；来源、修订、状态页、运行证据|
|四端入口模板|Codex、Cursor、ZCode、MiniMax Code；需用户装入各端规则；不是一键全自动配置|
|私有导入器|本项目 JSON 协议；增量、去重、旧内容恢复、暂停、软删除防重建、容量控制；不是 Takeout 通用解析器|
|Gemini Chrome 实验扩展|用户显式选择当前已加载会话，私有保存；已有 macOS 短会话实测；当前维护者在线采集暂停|
|摘要共享入口|用户选定摘要与项目后，经既有权限入口保存；原文不会自动共享|
|发行材料|无个人数据源码、MIT、两套离线演示、测试、CI 配置、安装及反馈说明|

核心不依赖 Node；扩展运行需要 Chrome。Python 3.10+，本机验证 macOS，Linux 仅配置了 CI，不能据此宣布支持已验收。原生 Windows 不支持。

## 稳定版与整体项目仍必须补齐

1. 外部新安装反馈；Cursor、ZCode 等客户端真实接力证据，不能用 CLI actor 模拟替代。
2. Gemini 长历史、复杂响应、真实账号切换验证；原生客户端与网页同步能力继续核实。在线验证保持暂停，须用户明确恢复。
3. 少量 ChatGPT 网页采集、更好的授权内检索、更多 Agent 接入，保留为原项目必做范围，尚未实现。
4. 已安装本机桥接仍为先前版本；本轮修复只进入发行源码。下次明确恢复前先按采集说明升级，不自动启动采集。

## 分享与回滚

用 README 试跑核心与私有导入；默认不要为试用发送 Gemini 测试消息。打开 Issue 使用合成内容，勿上传自己的权限清单、state.json、records 或完整工具日志。仓库发布前不要在文案中编造仓库地址、CI 徽章或安装量。

停用扩展：先执行 private_capture.py 的 pause，再在 Chrome 扩展管理页关闭该扩展；不删除原文。卸载桥接时，仅移除自己安装的 ai.local_agent_memory.capture.json 注册文件，保留私有目录；不要删除整个 Chrome 配置目录。升级前备份私有目录，关闭扩展，运行安装器；若提示 host/runtime 冲突，先核对旧根目录与 Python 路径，不强行覆盖。当前 installer 不提供自动迁移。
